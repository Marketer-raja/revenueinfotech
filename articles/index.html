Amazon has a plan to index the world’s online shopping data

Amazon is reportedly building a project called World Product Graph, which would gather data on almost every product sold anywhere in the world, including items Amazon does not stock. According to a Reuters exclusive, the aim is to keep shoppers on Amazon.com and give AI shopping agents a reason to start their searches there. Amazon disputes the report's figures on its own assistant, saying they are outdated.

Securing the agentic enterprise with data lineage

As companies let AI agents pull data from many systems at once, security teams are finding that guarding apps, networks and devices is not enough. A sponsored MIT Technology Review report, produced with security firm Cyberhaven, argues that organisations also need data lineage: a record of where data came from, how it changed and where it went.

Cloud Computing · November 04, 2026

Critical Rails Flaw Lets Attackers Write Server Files via Crafted ImageMagick Uploads

Rails has patched a critical flaw in its Active Storage upload component that could let an unauthenticated attacker write files to a server by uploading a specially crafted file, if the app processes uploads with ImageMagick. Fixed versions 8.0.5.2 and 8.1.4.1 were released on November 4, and teams are urged to upgrade and review their image-processing settings.

Software Development · November 04, 2026

Xen Hypervisor Flaws Let One Malicious VM Read and Write Any Other VM's Memory

The Xen Project has disclosed two flaws, tracked as XSA-523, that let a malicious virtual machine read and change the memory of other VMs on the same host, including the privileged control domain known as dom0. Patches are available, but there is no workaround, so operators of Xen-based servers need to update the hypervisor and restart the host.
