# Hybrid free-account setup
This package supersedes the earlier batch ZIP. Keep the mobile Newsdesk and ten-approved-article publishing queue. Draft collection is attempted every two hours, up to ten leads per run, not ten completed drafts per ten minutes. Shared workflow concurrency and hosting delays may postpone publishing. No cloud account or live endpoint has been tested.

## Configure only free accounts
Use https://aistudio.google.com/apikey, https://console.groq.com/keys, https://openrouter.ai/keys and https://console.mistral.ai/ to obtain optional API keys. Verify each account/project is free-only, with no paid billing, payment method, automatic credit purchases or paid fallback. If a free API is unavailable, leave it disabled. Models and quotas can change. Do not enable any service if you cannot verify that it cannot charge you. The software cannot inspect your billing plan or guarantee zero charges if you enable billing later.

In GitHub Settings > Secrets and variables > Actions, add repository secrets GEMINI_API_KEY, GROQ_API_KEY, OPENROUTER_API_KEY, MISTRAL_API_KEY for providers you want. Under Variables add corresponding GEMINI_FREE_CONFIRMED, GROQ_FREE_CONFIRMED, OPENROUTER_FREE_CONFIRMED, MISTRAL_FREE_CONFIRMED with value `yes` ONLY after checking free-only status. Missing confirmation disables the provider. The OpenRouter route is hard restricted to openrouter/free, with zero prompt/completion price. No paid fallback is configured. Each provider has a default 3-attempt cap per run (not a daily/account quota); API errors disable the provider for the rest of the run. Ollama is the fallback on the GitHub runner. Existing hosting/domain/electricity costs are separate. Public repositories only.

Enable read/write workflow permissions and run RevenueInfoTech editorial publishing manually. Inspect logs and verify Newsdesk before approving. The model receives headline metadata, not full verified research; draft validation is basic, not a fact or copyright guarantee. Independently open sources and verify every claim. Do not publish incomplete articles. Original illustrations are not event photos. Audit existing content before applying for AdSense.

## Optional n8n
Import n8n-hybrid-trigger.json in your self-hosted Community Edition. Replace REPLACE_OWNER and REPLACE_REPO, adjust branch if needed. Create Header Auth credentials with name Authorization and value Bearer YOUR_FINE_GRAINED_TOKEN (repository Actions write permission). Keep token private. Run manually to test. If activating the two-hour schedule in n8n, remove the schedule block from update-news.yml first to avoid duplicate runs. n8n only triggers GitHub; Python manages the AI providers. n8n must remain running for its own schedule. Without n8n GitHub schedules work independently. The publishing queue workflow remains separate.
